# 🎮 Dodge the Blocks

A simple 2D arcade game built with **Python** and **Pygame**.

The goal is to avoid falling blocks for as long as possible and get the highest score!

## 📸 About the Game

In this game, you control a blue square while red blocks fall from the top of the screen.

Every block you successfully dodge gives you **1 point**.

The longer you survive, the faster the blocks become!

## 🕹️ Controls

| Key | Action |
|---|---|
| `A` or `←` | Move left |
| `D` or `→` | Move right |
| `R` | Restart the game after losing |

## ✨ Features

- Simple and fun gameplay
- Random enemy spawning
- Increasing difficulty
- Score system
- Collision detection
- Game Over screen
- Restart functionality
- Smooth gameplay at 60 FPS

## 🛠️ Requirements

- Python 3.8 or newer
- Pygame

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_REPOSITORY
   ```

3. Install Pygame:

   ```bash
   pip install pygame
   ```

## ▶️ How to Run

Run the game using Python:

```bash
python main.py
```

Replace `main.py` with the name of your Python file if it is different.

## 🎯 Objective

Avoid the falling red blocks and survive as long as possible.

Try to beat your high score!
